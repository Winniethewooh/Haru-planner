    투두메이트 연결

    한 번만 설정해 두면, 가져오기를 누를 때마다 투두메이트의 오늘 할 일이 하루로 들어와요. 투두메이트 웹을 잠깐 거쳤다가 자동으로 돌아와요.

      처음 한 번만 하면 돼요

      1. App Store에서 Userscripts 앱을 설치해요 (무료).
      2. 아이폰 설정 › 앱 › Safari › 확장 프로그램 › Userscripts를 켜고, 모든 웹 사이트를 허용해요.
      3. 스크립트 열기를 누르고, 사파리 주소창 왼쪽의 퍼즐 모양 › Userscripts › 설치를 눌러요.
      4. 사파리에서 todomate.net에 로그인해 둬요.

      Userscripts 연결됨 ✓

      처음 가져올 때만 투두메이트 화면에 안내가 나와요. 안내대로 할 일을 손가락으로 눌러 알려 주세요 (완료 안 한 것 하나, 완료한 것 하나).

      투두메이트를 끄면 자동으로 가져오기

      투두메이트 앱을 끌 때마다 하루가 알아서 최신 할 일을 가져와요. 아이폰 단축어 앱에서 한 번만 만들어 두면 돼요.

      2. 단축어 앱 › 아래쪽 자동화 › + › 앱
      3. 투두메이트를 고르고 닫힘만 체크해요. 즉시 실행을 고르고, 실행 알림은 꺼요.
      4. 새로운 빈 자동화 › 동작 추가 › URL 열기에 복사한 주소를 붙여넣어요.

      끌 때마다 사파리가 잠깐 열렸다가 가져와요.

      아이폰 캘린더 일정 보기

      캘린더의 오늘 일정을 시간표에 회색 칸으로 보여줘요. 단축어 앱이 일정을 넘겨주는 방식이라 계정 연결은 필요 없고, 일정은 이 폰 안에만 저장돼요.

      2. 단축어 앱에서 새 단축어를 만들고 캘린더 이벤트 찾기를 추가해요 (시작일이 오늘).
      3. 각 항목에 대해 반복 안에 텍스트를 넣고 이렇게 적어요: 09:00-10:30 팀 미팅 (시각은 HH:mm 형식으로, 일정 이름이 뒤에 와요).
      4. 반복이 끝나면 텍스트 결합(새로운 줄) › URL 인코딩을 해요.
      5. URL 동작에 복사한 주소를 쓰고 그 뒤에 인코딩한 텍스트를 붙인 뒤, URL 열기를 해요.

      종일 일정과 새벽 2~6시 일정은 보이지 않아요.

      다른 방법: 북마크 버튼

      Userscripts 없이 쓰는 방법이에요. 가져오고 싶을 때마다 직접 눌러야 해요.

      2. 사파리 공유 버튼 › 북마크 추가 › 이름을 하루로 보내기로 해요.
      3. 북마크를 편집해서 주소를 모두 지우고 복사한 코드를 붙여넣어요.
      4. todomate.net에서 주소창에 하루를 입력하고 하루로 보내기를 눌러요.
      다른 방법: 글자로 붙여넣기

      할 일 목록을 직접 붙여넣어 쓰거나 시험해 볼 수 있어요. 한 줄에 하나씩 적고, 앞에 ☑를 붙이면 완료로 봐요.

      폰과 컴퓨터에서 같이 쓰기

      두 기기에서 같은 계획을 보고 싶을 때 켜요. 계획이 내 GitHub의 비공개 저장 공간(Gist)에 저장돼요. GitHub 토큰(gist 권한)이나, 다른 기기에서 복사한 연결 코드를 넣어 주세요.
