# 하루

할 일을 **오전 · 오후 · 저녁 · 밤**으로 배치하고, 10분 단위 **시간표**로 하루를 짜는 미니멀 하루 플래너. 할 일은 직접 넣거나 투두메이트에서 가져올 수 있어요.

빌드 없는 정적 웹앱이라 GitHub Pages 등에 그대로 올리면 됩니다.

## 할 일 넣기

- **직접 추가**: 계획 탭 맨 위 입력칸에 쓰고 엔터. 메모나 카톡에서 복사한 **여러 줄을 붙여넣으면 한 번에** 들어가요(앞의 `-`, 번호는 지우고, `☑`로 시작하는 줄은 완료로 넣어요).
- **전날 이어하기**: 오늘(또는 이후 날짜)을 열었을 때 전날 못 끝낸 할 일이 있으면 `전날 못 끝낸 할 일 N개 가져오기`가 나와요. 한 번 누르면 들어오고, `×`로 닫을 수 있어요.
- **투두메이트에서 가져오기**: 아래 설명. 설정 › `투두메이트 웹에서 가져오기`를 켜면 맨 위에 `가져오기` 버튼이 나타나요(이미 연결해 둔 분은 켜져 있어요).

## 투두메이트에서 가져오기 (아이폰)

투두메이트는 공식 연동이 없어서, 하루가 **투두메이트 웹(todomate.net)을 잠깐 거쳐** 화면에 보이는 할 일을 읽어 옵니다. 웹은 프리미엄이 필요하고, 구독하지 않아도 모바일 앱에서 광고를 보면 열 수 있어요.

> **주의**: 투두메이트 웹은 글자를 HTML이 아니라 캔버스에 그림으로 그리는 것으로 보여요(Flutter 웹). 그러면 목록 글자가 화면 안에 글자로 없어서 이 방법으로는 읽지 못해요. 읽을 수 없을 때는 안내만 띄우고 아무것도 가져오지 않으며, 코드 조각처럼 보이는 내용은 할 일로 넣지 않아요. 설정의 `가져온 항목 모두 지우기`로 잘못 들어온 항목을 정리할 수 있어요.
>
> 안내 카드가 다시 안 뜨면 설정의 `투두메이트 화면 설정 다시 하기`를 누르세요(저장된 위치를 지우고 처음부터 다시 안내해요). 투두메이트 페이지 오른쪽 아래에 작은 `하루로` 버튼이 보이면 스크립트가 돌고 있는 거예요. 안 보이면 Userscripts의 스크립트를 다시 설치해야 해요(이번 버전부터 `@downloadURL`이 있어서 Userscripts에서 업데이트 확인으로 받을 수 있어요).
투두메이트 앱에서 바꾼 내용은 같은 계정의 웹에도 그대로 보이니, 평소처럼 앱을 쓰면 돼요.
로그인 정보는 어디에도 보내지 않아요(화면에 보이는 할 일 제목·완료 여부만 하루로 넘김).

### 처음 한 번 설정

1. App Store에서 **Userscripts** 설치 (무료 사파리 확장)
2. 설정 › 앱 › Safari › 확장 프로그램 › Userscripts 켜기 › 모든 웹 사이트 허용
3. 하루 `···` › **스크립트 열기** › 주소창의 퍼즐 아이콘 › Userscripts › 설치
4. 사파리에서 todomate.net 로그인
5. 하루 `···` › **지금 가져오기** › 처음에만 완료 안 한 할 일 하나, 완료한 할 일 하나를 탭

### 매일

- **하루를 열면 끝.** 마지막으로 가져온 지 15분이 지났으면 투두메이트를 1~2초 거쳐 자동으로 돌아와요.
- 바로 가져오고 싶으면 `가져오기` 한 번.
- 사파리에서 투두메이트를 직접 열었을 땐 오른쪽 아래 작은 `하루로` 버튼이 보여요.
- 바뀐 부분만 반영: 새 항목은 `미배정`에 `•`, 지운 항목은 자리에 흐리게 남음(`×`로 정리). 배치한 시간대는 유지돼요.
- 잘못 읽히면 가져오는 중에 뜨는 카드의 `다시 지정`으로 위치를 다시 알려주세요.

### 맥북(사파리)에서 연동하기

Userscripts는 맥북 사파리에서도 같은 방식으로 써요 (macOS 12 이상, 사파리 14.1 이상).

1. Mac App Store에서 **Userscripts**를 설치하고, 앱을 한 번 열어서 스크립트를 저장할 폴더를 정해요.
2. 사파리 **설정 › 확장 프로그램**에서 **Userscripts**를 켜고, 권한을 **모든 웹 사이트에서 항상 허용**으로 해요.
3. 사파리에서 `<하루 주소>/haru.user.js`를 열고 툴바의 Userscripts 아이콘을 눌러 **설치**해요.
4. 같은 사파리에서 todomate.net에 로그인해 둬요.
5. 하루를 열고 **가져오기**를 눌러요. 처음에만 투두메이트 화면에서 안내대로 할 일을 눌러 알려 주고, 허용 확인 카드에서 하루 주소를 허용해요.

맥북과 아이폰에서 같은 계획을 보려면 `···` › "폰과 컴퓨터에서 같이 쓰기"를 두 기기에 모두 연결하세요. 단축어 자동화와 캘린더 단축어는 맥북 단축어 앱에서도 만들 수 있어요. 하루는 **사파리 탭**에서 쓰고, 메뉴의 "Dock에 추가"로 만든 앱은 저장 공간이 따로라서 가져온 내용이 안 보여요.

### 다른 날 보기 (주 · 월)

하루를 열면 **오늘**이 기본이에요. 맨 위 달력에서 다른 날을 눌러 그날의 계획과 시간표를 보고 고칠 수 있어요.
- 기본은 **주 보기**(일~토 한 줄)이고, `10월 ⌄`를 누르면 **월 보기**로 펼쳐져요. 화살표(‹ ›)는 주 보기에서 한 주, 월 보기에서 한 달씩 옮겨요. 다른 날을 보고 있으면 `오늘`로 바로 돌아올 수 있어요.
- 날짜 아래 점은 그날 기록이 있다는 표시이고, 할 일을 모두 끝낸 날은 점이 진해요.
- 다른 날에도 할 일 직접 추가, 시간표 배치, 편집이 되고, 내일 이후 계획도 미리 세울 수 있어요.
- 투두메이트 가져오기와 자동 가져오기는 **오늘** 기준이에요. 기기 간 동기화도 지금은 오늘 계획만 해서, 다른 날 기록은 그 기기에만 저장돼요.

### 시간표에서 일정 편집

시간표에 넣어 둔 블록을 **한 번 누르면** 편집 시트가 열려요. `완료`를 체크하면 계획 탭과 같이 완료 처리되고(시간표에서는 ✓와 연한 색으로 보여요), 8가지 색 중에서 색을 바꿀 수 있고, `이 시간 비우기`로 그 블록을 지울 수 있어요. 블록을 길게 누르면 옮기기·늘이기예요.

### 할 일 직접 추가

투두메이트에 없는 할 일은 하루에서 바로 만들 수 있어요. 계획 탭 맨 위 입력칸에 이름을 쓰고 `추가`를 누르면 `미배정`에 들어가고, 시간표에서 시간 범위를 고를 때 나오는 입력칸에 쓰면 그 시간에 바로 들어가요. 직접 추가한 항목은 투두메이트에서 가져오기를 해도 지워지거나 바뀌지 않아요. 항목을 눌렀을 때 나오는 `삭제`로 지울 수 있어요(투두메이트 항목은 투두메이트에서 지워요).

### 시간표 탭

상단 `계획 / 시간표`로 전환해요. 하루를 **10분 칸 6개 × 20줄**(오전 6시 시작, 새벽 2시에 끝)로 보여주고, 시간 칸을 누르거나 끌어서 범위를 고르면 아래에서 **아직 시간표에 없는 할 일**이 먼저 올라오고(이미 넣은 할 일은 `이미 넣은 할 일에도 시간 더하기`를 눌러야 보여요), 고르면 그 범위가 이름이 적힌 하나의 블록이 돼요. 시간대가 비어 있던 할 일은 그 시각의 시간대(오전·오후·저녁·밤)로 같이 배정돼요. 넣어 둔 블록을 **길게 누른 채 끌면** 블록이 통째로 따라와서 놓은 시간으로 옮겨져요. 블록의 **앞·뒤 가장자리**(칸의 바깥쪽 3분의 1)를 길게 누른 채 끌면 그쪽 시간이 늘어나거나 줄어들어요. 놓은 자리에 있던 다른 블록은 덮어써요. 칠한 칸을 골라 `이 시간 비우기`로 지울 수 있어요. 한 줄 높이는 `···` 설정의 `시간표 줄 높이`(좁게·보통·넓게·아주 넓게)에서 고를 수 있어요. 현재 시각은 왼쪽에 빨간 시각 표시로, 지금 10분 칸은 빗금으로 보여요. 기기 간 동기화를 켜 두면 시간표도 같이 동기화돼요.

### 안전하게 쓰기 (공개 주소로 올릴 때)

- 하루는 서버가 없는 정적 웹앱이라 할 일·시간표·캘린더는 **내 기기(브라우저)에만** 저장돼요. 기기 간 동기화를 켰을 때만 내 GitHub 비공개 Gist로 가요.
- 투두메이트 로그인 정보는 읽지도 보내지도 않아요. 화면에 보이는 할 일 제목과 완료 여부만 넘겨요.
- `todomate.net/#haru=<주소>` 링크는 누구나 만들 수 있어서, Userscripts는 **처음 보는 하루 주소로는 보내기 전에 꼭 물어봐요**(`허용하고 보내기`). 한 번 허용한 주소로만 돌아가고, `https`가 아닌 주소(`localhost` 제외)는 무시해요.
- 주소로 들어오는 할 일·일정은 개수와 길이를 제한하고 항상 글자로만 표시해요.
- 화면 보안 정책(CSP)으로 외부 스크립트 실행과 임의 서버로의 전송을 막아 뒀어요(허용: 같은 사이트와 GitHub API뿐. 폰트도 `fonts/`에 직접 넣어 외부 CDN을 쓰지 않아요).
- `···` 설정 맨 위의 **연동 상태**에서 Userscripts 연결, 마지막으로 가져온 시각·개수, 가져온 목록을 눈으로 확인할 수 있어요.

### 아이폰 캘린더 가져오기 (단축어)

웹앱은 캘린더를 직접 읽을 수 없어서 **단축어** 앱이 오늘 일정을 하루로 넘겨요. 계정 연결이 필요 없고 일정은 기기 안에만 저장돼요.
`···` › "아이폰 캘린더 일정 보기"에서 주소를 복사한 뒤 단축어를 만드세요.

1. **캘린더 이벤트 찾기**(시작일이 오늘)
2. **각 항목에 대해 반복** › 텍스트 `시작 시각-종료 시각 제목` (날짜 포맷을 `HH:mm`로, 예: `09:00-10:30 팀 미팅`)
3. **텍스트 결합**(새로운 줄) › **URL 인코딩**
4. **URL**: `<복사한 주소>` 뒤에 인코딩한 텍스트를 붙임 › **URL 열기**

시간표에 회색 블록으로 보여요. 종일 일정과 새벽 2~6시 일정은 표시하지 않아요. 단축어 자동화(예: 아침마다)로 돌려도 돼요.

### (선택) 투두메이트 앱을 닫으면 자동으로 갱신

하루 `···` › "투두메이트를 끄면 자동으로 가져오기"에 같은 안내와 주소 복사 버튼이 있어요.

1. 하루 `···` › **주소 복사** (`https://<하루 주소>/#sync`)
2. 단축어 앱 › 자동화 › `+` › **앱**
3. 앱: 투두메이트 · **닫힘**만 선택 · **즉시 실행** · 실행 시 알림 끄기
4. 새로운 빈 자동화 › 동작 추가 › **URL 열기** › 복사한 주소

투두메이트를 닫을 때마다 사파리에서 하루가 열리고 1~2초 뒤 갱신돼요. 1분 안에 여러 번 닫으면 한 번만 가져와요.
단축어는 매번 새 사파리 탭으로 열 수 있어서, 탭이 쌓이면 설정 › Safari › 탭 닫기 › "하루 후"를 권해요.

### 알아둘 점

- 하루는 **사파리 탭**에서 쓰세요. "홈 화면에 추가" 앱은 사파리와 저장 공간이 따로라서 가져온 내용이 안 보여요.
  (홈 화면 앱을 쓰려면 아래 `기기 간 동기화`를 연결하세요.)
- 투두메이트 웹에 **지금 보이는 날짜**의 목록을 읽어요(보통 오늘).
- 자동 가져오기는 `···` › "하루를 열 때 자동으로 가져오기"로 끌 수 있어요.
- 확장을 쓰기 싫으면 `···` › "다른 방법: 북마크 버튼"으로 같은 기능을 북마크 버튼으로 쓸 수 있어요(매번 직접 눌러야 함).

## 그 밖의 가져오기

- **텍스트로 붙여넣기** (`···` › 텍스트로 붙여넣기): 한 줄에 하나.
  불릿(`-` `•` `1.`), 완료 표시(`☑ ✓ [x]`)/미완료 표시(`☐ [ ]`), `카테고리:` 또는 `# 카테고리` 줄을 인식합니다.
- **PC 크롬 확장** (`extension/`, 선택): PC에 투두메이트 웹을 켜 두면 6시간마다 읽어 보냅니다.
  `기기 간 동기화`를 연결해야 해요. 버튼과 같은 방식(`extension/extractor.js`)으로 할 일을 읽어요.

## 기기 간 동기화 (선택)

폰과 PC에서 같은 계획을 보고 싶을 때만 필요해요. GitHub 비공개 Gist에 배치를 저장합니다.

1. GitHub › Settings › Developer settings › Personal access tokens 에서 토큰 만들기
   (classic: `gist` 권한만 / fine-grained: Account permissions › Gists: Read and write)
2. 하루 앱 `···` › 기기 간 동기화 › 토큰 붙여넣고 `연결` → `연결 코드 복사`
3. 다른 기기에서는 같은 곳에 연결 코드를 붙여넣기

앱을 열 때 최신 계획을 받아오고, 배치를 바꾸면 바로 올립니다.
연결 코드에는 토큰이 들어 있으니 공유하지 마세요.

### PC 크롬 확장 설치 (선택)

1. `chrome://extensions` › 개발자 모드 › `압축해제된 확장 프로그램 로드` › `extension/` 폴더
2. 확장 아이콘 › 연결 코드 붙여넣기
3. todomate.net 오늘 화면에서 확장 아이콘 › `할 일 위치 지정`
   › 완료하지 않은 할 일 클릭 › 같은 카테고리의 완료한 할 일 클릭(없으면 Esc)
